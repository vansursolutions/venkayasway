# venkayaswamy.com — Sri Venkaiah Swamy Temple, Sullurupeta

A simple bilingual (English / Telugu) website that also installs as a mobile app (PWA) and
ships as an Android app (Capacitor). No build step: the site is plain HTML, CSS and JS in `www/`.

## Folder layout

```
www/                 the website (this folder is deployed as-is)
  index.html         home
  life.html          life story
  teachings.html     teachings
  temple.html        timings, festivals, address, directions
  gallery.html       photos and videos
  donate.html        donations and contact form
  css/style.css      styles
  js/site.js         header, footer, language toggle, PWA install
  images/            photos (replace the placeholders)
  icons/             app icons (regenerate with `npm run icons`, or drop in your own)
  manifest.webmanifest, sw.js   PWA files
android/             Android project generated by Capacitor
tools/make-images.py generates placeholder images and icons
```

## Editing content

Every piece of text appears twice, wrapped in `<span class="en">…</span>` and `<span class="te">…</span>`.
Only the chosen language is shown; the toggle in the header switches between them.

Search the pages for `TODO` — those are placeholders that need real information:
temple address and phone, timings, bank / UPI details, Formspree form id, photos, video ids.

## Run locally

```
npm run dev          # then open http://localhost:3000
```

## Deploy the website (free hosting)

Any static host works. Recommended: Cloudflare Pages or Netlify.

1. Push this folder to a GitHub repository.
2. In Cloudflare Pages (or Netlify) create a project from that repo.
   Build command: none. Output / publish directory: `www`.
3. Add the custom domain `venkayaswamy.com` in the host's dashboard.
4. At your domain registrar, set the DNS records the host shows you
   (usually a CNAME for `www` and an A / ALIAS record for the root).
5. HTTPS is issued automatically. The site is then installable as an app on Android and iOS
   ("Add to Home Screen").

When you change files, bump `CACHE` in `www/sw.js` (v1 → v2) so phones fetch the new version.

## Android app (Play Store)

One-time setup:
1. Install Android Studio from https://developer.android.com/studio (includes the SDK).
2. Open Android Studio once and let it finish installing the SDK.

Build and run:
```
npm run android:sync     # copy www/ into the Android project (run after every site change)
npm run android:open     # opens android/ in Android Studio; press Run to test on a phone/emulator
```

Publish:
1. In Android Studio: Build → Generate Signed Bundle / APK → Android App Bundle. Create a keystore
   and keep it safe (you need the same keystore for every future update).
2. Create a developer account at https://play.google.com/console (one-time fee).
3. Create the app, upload the `.aab`, fill in the store listing (screenshots, description, privacy
   policy URL — a page on venkayaswamy.com is fine), and submit for review.

App id: `com.venkayaswamy.app` (in `capacitor.config.json`). App name and icon: `android/app/src/main/res/`.
To use your own icon in the app, replace the files under `android/app/src/main/res/mipmap-*`
or use Android Studio: right-click `res` → New → Image Asset.
